RetroXR is free and open source. It runs on **Meta Quest** and on **Windows** — as PCVR
with a headset attached, or in a desktop mode with mouse and keyboard without one. Since
v0.10.0 there are also **Linux** and **macOS** builds, which are experimental.

| Platform | File | Status |
| --- | --- | --- |
| Meta Quest 2 / 3 / Pro | `RetroXR-v<version>.apk` | Supported |
| Windows (desktop and PCVR) | `RetroXR-win-v<version>.zip` | Supported |
| Linux x86_64 | `RetroXR-linux-x86_64-v<version>.AppImage` | Experimental |
| Linux arm64 | `RetroXR-linux-arm64-v<version>.tar.gz` | Experimental |
| macOS (Apple Silicon and Intel) | `RetroXR-macos-arm64-v<version>.zip` | Experimental |

## Meta Quest

RetroXR is not on the Horizon Store, so it has to be **sideloaded**. That sounds more
involved than it is: you turn on developer mode once, install a free tool on your PC, and
after that it is a single click.

Quest 2, Quest 3 and Quest Pro are all supported, with the same install process. Most
testing happens on a **Quest 3**.

### Step 1 — Turn on Developer Mode

<Steps>

1. Install the **Meta Horizon** app on your phone, if it is not already there, and make
   sure it is paired with your headset.

2. Create a developer organization at
   [developers.meta.com](https://developers.meta.com/horizon/manage/organizations/create).
   It is free, and it only asks for a name — you are not signing up for anything.

3. In the Meta Horizon phone app, open your headset's settings, find **Developer Mode**,
   and turn it on.

4. Reboot the headset.

</Steps>

<Aside type="caution">
	Developer Mode will not appear in the phone app until your Meta account belongs to a
	developer organization. If the toggle is missing, step 2 is the one that was skipped.
</Aside>

### Step 2 — Install SideQuest on your PC

Download **SideQuest Advanced Installer** from
[sidequestvr.com/setup](https://sidequestvr.com/setup) and install it. It is available for
Windows, macOS and Linux.

### Step 3 — Connect the headset

<Steps>

1. Plug the headset into your computer with a USB-C cable.

2. Put the headset on. You will be asked to **Allow USB debugging** — accept it, and check
   *Always allow from this computer* so you are not asked again.

3. Back on the PC, SideQuest's indicator in the top-left should turn green.

</Steps>

### Step 4 — Install RetroXR

<Tabs>
<TabItem label="From the SideQuest listing">

Open the [RetroXR listing](https://sidequestvr.com/app/61366) and press
**Install to Headset**. That is the whole thing.

</TabItem>
<TabItem label="From the APK">

Download `RetroXR-v<version>.apk` from the
[latest release](https://github.com/RetroXR/RetroXR/releases/latest), then drag the
file onto the SideQuest window — or use the *Install APK file from folder* button in
SideQuest's top-right toolbar.

</TabItem>
</Tabs>

### Step 5 — Launch it

In the headset, open the app library and switch the source dropdown from *All* to
**Unknown Sources**. RetroXR is in there. Sideloaded apps never appear in the main
library list, which is the single most common "where did it go?" moment.

<Aside type="tip" title="Upgrading later">
	Installing a newer version over an old one keeps your saves, settings and downloaded
	cores. There is no need to uninstall first.
</Aside>

## Windows

<Steps>

1. Download `RetroXR-win-v<version>.zip` from the
   [latest release](https://github.com/RetroXR/RetroXR/releases/latest).

2. Unpack it somewhere sensible — not inside `Downloads`, since the app writes its data
   folder alongside your user profile.

3. Run `RetroXR.exe`.

</Steps>

If an **OpenXR runtime** is running with a headset attached — SteamVR, or the Meta Quest
Link app with a Quest over Link or Air Link — RetroXR runs as **PCVR**. With no headset it
falls back to a **desktop mode** with mouse and keyboard — see the
[desktop controls](/guide/reference/desktop-controls/).

## Linux and macOS

Both have packaged builds on the
[latest release](https://github.com/RetroXR/RetroXR/releases/latest) since v0.10.0. They
are **experimental**: they are built with every release, but tested far less than the
Quest and Windows builds.

<Tabs>
<TabItem label="Linux">

Download the **AppImage** for x86_64, or the **tar.gz** for arm64. Mark the AppImage
executable and run it; unpack the tarball and run the executable inside it.

- The DVD player and the VCR use your system's libVLC, so install your distro's
  **`vlc-libs`** package (on some distros just `vlc`). Without it the rest of the app works
  and those two do not.
- SDL3, for game controllers, ships beside the binary — there is nothing to install.

</TabItem>
<TabItem label="macOS">

Download the **macOS** zip — one build for both Apple Silicon and Intel Macs — and unzip
it.

- The app is ad-hoc signed rather than notarized, so the first time, **right-click it and
  choose Open** rather than double-clicking.
- Emulator cores download **unsigned by design**; that is expected.
- There is **no DVD player, no VCR and no HRTF spatial audio** on macOS: there is no
  packaged libVLC for the Mac yet, and Meta publishes its spatial audio library only for
  Windows and Android. Everything else is there, and cores that render with Vulkan run
  through MoltenVK.

</TabItem>
</Tabs>

If you would rather build either from source, the
[README in the repository](https://github.com/RetroXR/RetroXR#building) has the full
recipe.

## Updating on desktop

The Windows, Linux and macOS builds check GitHub for a newer release shortly after launch.
When one is out, a banner appears on the menu: press **Update** and RetroXR downloads it,
checks it against the release's checksum, swaps the files and restarts — with your room
as you left it. Nothing is installed until you press the button, and the check can be
switched off under `OPTIONS` → ABOUT → **Updates**.

## Where your files go

RetroXR reads your games, videos, discs and books out of one folder tree:

```
roms/      ROM files, one folder per system
books/     .pdf and .cbz
videos/    .mp4 .mkv .avi .webm .mov
dvd/       a VIDEO_TS folder, or an .iso / .img
music/     audio for the CD player, tape deck and turntable
```

Where that tree lives depends on the platform:

| Platform | Location |
| --- | --- |
| Windows | `%USERPROFILE%\retroxr` |
| Linux / macOS | `~/retroxr` |
| Quest | `/sdcard/Android/data/com.xenu.retroxr/files` |

On a headset you do not have a file manager, so RetroXR includes one — turn on **Web File
Manager** in `OPTIONS`, and copy files over from any browser on your network. That is the
route to use on Quest, and it is covered step by step in
[adding your games](/guide/adding-games/).

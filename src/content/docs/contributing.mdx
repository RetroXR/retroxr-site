RetroXR is a hobby project built in spare time, and help of almost any kind goes a long
way. All of these are genuinely useful:

- **Bug reports with a log.** The single most useful thing you can send. See
  [reporting bugs](/guide/reference/reporting-bugs/) for how to get the log.
- **Testing on hardware other than a Quest 3.** Quest 2 and Quest Pro, PCVR headsets, and
  the experimental Linux and macOS builds all get far less testing than they deserve.
- **Documentation fixes.** Every page on this site has an **Edit page** link at the bottom
  that opens it on GitHub.
- **Recordings and measurements of real hardware.** How a thing sounds, how big it is,
  where its sockets really are. The Game Boy Printer's sound, for one, is a guess that a
  recording would replace.
